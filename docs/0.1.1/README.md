# 0.1.1

Version bumped 2026-09-24. The release is fixes plus three small features; nothing here is
large. In the order the work is done (owner, 2026-09-24):

1. `03-rail-search-and-column-filter.md` — Search as the rail's first entry, and the columns
   view's filter narrowing the column the keyboard is in. ½ day each.
2. `02-rustix.md` — `rustix` out of the daemon, four call sites to `libc`. ½ day.
3. `01-info-popover.md` — the inspector in side by side as a callout on the selected row, and
   the info panel over a selection of many. 3½ days.

4. `05-wire-in-the-connection-log.md` — what was sent to an SFTP or FTPS server and what it
   answered, in the connection log. ½ day.
5. `06-toast-in-the-bar.md` — the toast as the bottom bar's message, in the shortcut chips'
   place. ½ day.

`04-fixes.md` is the running list of defects fixed as they come, each with its test.
