# 0.2.0

Version bumped 2026-09-24, the day 0.1.1 was released ("next release will be 0.2.0"). The
plans so far, in no settled order:

1. `01-dependencies.md` — the daemon's dependency survey and what to do about it (its first
   item was done ahead of this release).
2. `02-localization.md` — English, Spanish and Japanese, chosen by the OS setting. **Built in full, 2026-09-25**, numbered daemon errors and plugin form values included; every dialog photographed in Spanish and Japanese and what clipped fixed; the Spanish and Japanese are machine drafts awaiting a native reader.

3. `04-keys.md` — the Vim letters are the keys, the preference and type-ahead gone, `y x p v r dd z f : m .` and `Ctrl+T` added; the bottom bar's shortcut chips behind a preference, off. **Built 2026-09-25.**
4. `05-quicklook.md` — Quick Look: `Space` (and a double-click) opens a floating window showing the file itself — images, PDFs page by page, videos playing, Markdown with a folding table of contents — local or fetched from a server; the window floats above everything by a Hyprland rule Settings › Omarchy installs. **Built 2026-09-25** (four agents, one integrator).

`03-fixes.md` is the running list of defects fixed as they come, each with its test.
